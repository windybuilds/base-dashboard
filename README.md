# Base Asset Dashboard 🚀

一个基于 **Base 网络** 的去中心化资产看板，实时展示钱包余额与多链资产分布。

## ✨ 功能特点

- **实时可视化**：使用 ECharts 展示资产分布，支持多网络切换（Ethereum、Base、Arbitrum、Optimism 等）
- **钱包交互**：一键连接 MetaMask、Coinbase Wallet 等主流 Web3 钱包
- **安全设计**：采用**非托管（Read-only）**模式，仅读取链上公开数据，保护用户私钥安全
- **多端支持**：PC 端完美适配，移动端体验持续优化中
- **AI 辅助开发**：结合 AI 工具快速迭代功能

## 🛠 技术栈

- **前端框架**：Vue 3 + Vite
- **链上交互**：Ethers.js
- **数据可视化**：ECharts
- **部署平台**：Vercel
